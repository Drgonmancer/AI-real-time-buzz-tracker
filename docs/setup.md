# 安装与配置

> 完整配置说明见 [configuration.md](configuration.md)

## 快速步骤

1. Node.js 18+
2. `cd server && copy .env.example .env`
3. 填写 `DEEPSEEK_API_KEY`，确认 `DATABASE_URL="file:./dev.db"`
4. 双击 `start.bat` 或按 [quickstart.md](quickstart.md) 手动启动
