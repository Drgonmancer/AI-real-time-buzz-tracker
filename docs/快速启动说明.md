# 快速启动说明

> 项目：AI 热点监控工具（Pulse）  
> 更新日期：2026-06-03

---

## 1. 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10+ / macOS / Linux |
| Node.js | **18.0 及以上** |
| 磁盘空间 | 约 500MB（含 node_modules） |
| 浏览器 | Chrome / Edge / Firefox 最新版 |

**无需预先配置 API Key** 即可使用热点采集、列表浏览、关键词搜索。

---

## 2. 获取代码

```bash
git clone <你的仓库地址>
cd AI热点监控工具
```

或直接解压项目文件夹到本地。

---

## 3. Windows 一键启动（推荐）

1. 确认已安装 [Node.js 18+](https://nodejs.org/)（安装时勾选 **Add to PATH**）
2. 双击项目根目录 **`start.bat`**
3. 等待脚本完成（会自动：清理旧进程 → 安装依赖 → 初始化数据库 → 启动前后端）
4. 浏览器打开：**http://localhost:5173**

脚本会打开两个命令行窗口，请保持运行：

| 窗口标题 | 服务 | 端口 |
|---------|------|------|
| Pulse-Backend | 后端 API | 3000 |
| Pulse-Frontend | 前端 | 5173 |

**停止服务：** 双击 `stop.bat`，或关闭上述两个窗口。

**启动日志：** 项目根目录 `startup.log`

---

## 4. macOS / Linux 手动启动

```bash
# 1. 安装依赖并初始化数据库
bash scripts/setup.sh

# 或分步：
npm run install:all
npm run db:setup

# 2. 复制环境变量（可选）
cp server/.env.example server/.env

# 3. 启动后端（终端 1）
npm run dev:server

# 4. 启动前端（终端 2）
npm run dev:client
```

浏览器访问：**http://localhost:5173**

---

## 5. 验证是否启动成功

### 5.1 后端健康检查

浏览器或 curl 访问：

```
http://localhost:3000/health
```

应返回：

```json
{ "status": "ok", "timestamp": "..." }
```

### 5.2 前端页面

- Dashboard 顶部显示 **LIVE**（WebSocket 已连接）
- 等待 1～3 分钟后热点列表应有数据（首次爬取需时间）
- 若无数据，点击 **REFRESH** 或检查 Pulse-Backend 窗口是否有报错

### 5.3 API 冒烟测试

```
http://localhost:3000/api/v1/hot-topics?page=1&pageSize=5
```

应返回 `success: true` 和 `topics` 数组。

## 6. 首次使用建议流程

1. **浏览热点** — 打开 Dashboard，查看默认 MIX 排序列表
2. **搜索关键词** — 顶部搜索栏输入如「AI」，点击 SEARCH
3. **配置关键词组（可选）** — 进入 Settings → KEYWORD_GROUPS，添加关注词
4. **配置 AI Key（可选）** — Settings → AI_ENGINE，保存 DeepSeek Key
5. **勾选分析** — 回到 Dashboard，勾选若干热点 → 点击 **AI ANALYZE (N)**

## 7. 端口说明

| 服务 | 地址 | 用途 |
|------|------|------|
| 前端 | http://localhost:5173 | 用户界面 |
| 后端 API | http://localhost:3000/api/v1 | REST 接口 |
| 健康检查 | http://localhost:3000/health | 探活 |
| WebSocket | ws://localhost:3000 | 实时推送 |

端口被占用时，`start.bat` 会尝试清理 3000/5173 上的旧进程。仍失败请手动结束占用进程后重试。

## 8. 常见问题

### Q1：Dashboard 显示 AWAITING SIGNAL / 加载失败

**原因：** 后端未启动或端口不对。

**处理：**

1. 确认 Pulse-Backend 窗口无报错
2. 访问 http://localhost:3000/health 是否正常
3. 重新运行 `start.bat`

### Q2：Node.js 未找到

安装 Node.js 18+ 并重启终端。Windows 下 `start.bat` 会优先查找 `Program Files\nodejs\`。

### Q3：Prisma / 数据库初始化失败

1. 关闭所有 Pulse 相关窗口
2. 运行 `stop.bat`
3. 删除 `server/dev.db` 后重新 `start.bat`（会重建库）

### Q4：AI 分析按钮灰色或提示未配置

进入 **Settings** 保存 DeepSeek API Key，或参考 [人工配置.md](./人工配置.md)。

### Q5：国际源（Reddit、Google News）无数据

需配置代理或系统 VPN，见 [人工配置.md](./人工配置.md) 中的 `HTTPS_PROXY`。
