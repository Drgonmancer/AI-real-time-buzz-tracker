# 人工配置文档

> 项目：AI 热点监控工具（Pulse）  
> 配置文件：`server/.env`（由 `server/.env.example` 复制）  
> 更新日期：2026-06-03

---

## 1. 配置方式概览

本项目支持 **两种方式** 配置 AI 与其它选项：

| 方式 | 适用场景 | 持久化 |
|------|---------|--------|
| **Web 设置页** | DeepSeek API Key、模型名、连接测试、删除 Key | Key 存 SQLite `users.apiKey` |
| **server/.env 文件** | 端口、爬虫间隔、代理、Twitter Token 等 | 文件持久化，重启生效 |

**API Key 优先级：** `.env` 中的 `DEEPSEEK_API_KEY` **高于** 数据库存储。若两处都配置，以 `.env` 为准；通过 UI 删除 Key 不会修改 `.env` 文件内容。

---

## 2. 首次创建 .env

### Windows

`start.bat` 首次运行时会自动：

```
server/.env.example  →  server/.env
```

### 手动

```bash
cp server/.env.example server/.env
```

## 3. Web 界面配置（Settings 页）

路径：前端 **Settings** → **AI_ENGINE**

### 3.1 保存 API Key

1. 在 **API_CREDENTIALS** 输入 DeepSeek Key（格式通常以 `sk-` 开头）
2. 可选修改 **MODEL_IDENTIFIER**（默认 `deepseek-chat`）
3. 点击 **TEST CONNECTION** 验证连通性
4. 点击 **SAVE CONFIG** 保存

保存后：

- Key 写入数据库，服务重启后自动加载
- 界面仅显示脱敏 hint（如 `sk-...abc1`），不显示完整 Key
- 输入框清空，避免 Key 残留在页面

### 3.2 删除 API Key

1. 当已配置 Key 时，会出现 **DELETE API KEY** 按钮
2. 确认后清除数据库与当前运行时配置
3. AI 分析功能立即不可用，热点采集与搜索不受影响

> 若 `.env` 中仍有 `DEEPSEEK_API_KEY`，重启服务后 Key 会再次从环境变量加载。需同时清空 `.env` 中对应行。

### 3.3 关键词组

同一 Settings 页 **KEYWORD_GROUPS** 区域：

- 创建组：组名 + 逗号分隔关键词
- 启用/停用、编辑、删除
- **仅启用状态** 的组参与 AI 相关性分析

---

## 4. Dashboard AI 分析操作

1. 在热点列表左侧 **勾选** 要分析的热点（可跨页选择）
2. 工具条可 **全选本页** / **清空选择**
3. 点击 **AI ANALYZE (N)**，仅分析已选 N 条（N ≤ 50）
4. 分析完成后列表自动刷新，显示评分与摘要

未配置 Key 时按钮不可用或提示先在 Settings 配置。

## 5. 环境变量详解（server/.env）

### 5.1 基础服务

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 3000 | 后端监听端口 |
| `NODE_ENV` | development | 运行环境 |
| `DATABASE_URL` | file:./dev.db | SQLite 路径（相对 server 目录） |
| `LOG_LEVEL` | debug | 日志级别 |

### 5.2 DeepSeek AI（可选）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DEEPSEEK_API_KEY` | 空 | DeepSeek API Key；不配则跳过 AI |
| `DEEPSEEK_BASE_URL` | https://api.deepseek.com/v1 | API 地址 |
| `DEEPSEEK_MODEL` | deepseek-chat | 模型名称 |
| `AI_DAILY_BUDGET` | 50 | 设置页展示的日预算上限（元，展示用） |
| `AI_MAX_TOPICS_PER_RUN` | 50 | 单次分析条数上限 |
| `AI_ANALYSIS_INTERVAL` | 300000 | 预留：自动分析间隔（毫秒） |

**获取 Key：** 登录 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建 API Key。

### 5.3 爬虫开关与间隔

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `SCRAPER_ENABLED` | true | `false` 关闭全部定时采集 |
| `SCRAPER_INTERVAL_BAIDU` | 300000 | 百度，毫秒（5 分钟） |
| `SCRAPER_INTERVAL_WEIBO` | 300000 | 微博 |
| `SCRAPER_INTERVAL_DOUYIN` | 600000 | 抖音（10 分钟） |
| `SCRAPER_INTERVAL_BILIBILI` | 600000 | B 站 |
| `SCRAPER_INTERVAL_GITHUB` | 3600000 | GitHub（1 小时） |
| `SCRAPER_INTERVAL_HACKERNEWS` | 900000 | HN（15 分钟） |
| `SCRAPER_INTERVAL_TWITTER` | 900000 | Twitter 趋势 |
| `SCRAPER_INTERVAL_REDDIT` | 1800000 | Reddit（30 分钟） |
| `SCRAPER_INTERVAL_BINGNEWS` | 1800000 | Bing News |
| `SCRAPER_INTERVAL_GNEWS` | 900000 | Google News 系列 |

### 5.4 第三方 Token（可选）

| 变量 | 说明 |
|------|------|
| `TWITTER_BEARER_TOKEN` | [twitterapi.io](https://twitterapi.io) 的 X-API-Key，非官方 Twitter Bearer |

未配置时 Twitter 相关采集/搜索返回空，不影响国内源。

### 5.5 网络代理（国际源）

| 变量 | 示例 | 说明 |
|------|------|------|
| `HTTPS_PROXY` | http://127.0.0.1:7890 | Reddit、Google News 等走代理 |

也可使用系统级 VPN，不配置 `HTTPS_PROXY` 时依赖系统网络。

### 5.6 WebSocket / CORS

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `WS_CORS_ORIGIN` | http://localhost:5173 | 必须与前端访问地址一致 |
| `WS_PING_TIMEOUT` | 60000 | Socket 超时 |
| `WS_PING_INTERVAL` | 25000 | 心跳间隔 |

若修改前端端口（如 5174），需同步修改此项并重启后端。

### 5.7 通知相关（预留）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `NOTIFICATION_MIN_SCORE` | 70 | WS 推送新热点的最低 AI 分 |
| `NOTIFICATION_QUIET_START` | 23:00 | 静默时段开始 |
| `NOTIFICATION_QUIET_END` | 08:00 | 静默时段结束 |

## 6. 能力矩阵（是否必须配置）

| 功能 | 最低要求 |
|------|---------|
| 国内热点采集（百度/微博/B 站等） | 无，开箱可用 |
| Dashboard 列表 / 筛选 / 排序 | 无 |
| 关键词跨平台搜索 | 无 |
| AI 智能分析 | DeepSeek API Key（UI 或 .env） |
| Twitter 数据 | `TWITTER_BEARER_TOKEN` |
| Reddit / GNews 稳定访问 | `HTTPS_PROXY` 或 VPN |

## 7. 配置示例

### 7.1 仅本地体验（零配置）

保持 `.env` 默认即可，`DEEPSEEK_API_KEY` 留空。

### 7.2 启用 AI（推荐 UI 配置）

1. 启动项目
2. Settings 页保存 Key  
   **或** 在 `.env` 写入：`DEEPSEEK_API_KEY=sk-你的密钥`

### 7.3 完整能力（含国际源 + Twitter）

```env
DEEPSEEK_API_KEY=sk-xxxxxxxx
HTTPS_PROXY=http://127.0.0.1:7890
TWITTER_BEARER_TOKEN=your_twitterapi_io_key
WS_CORS_ORIGIN=http://localhost:5173
SCRAPER_ENABLED=true
```

修改 `.env` 后需 **重启后端**（Pulse-Backend 窗口）。

---

## 8. 安全建议

1. **不要将 `.env` 提交到 Git**（已在 `.gitignore`）
2. 共享机器上使用完毕后，在 Settings 点击 **DELETE API KEY**
3. Key 泄露时，在 DeepSeek 控制台立即轮换密钥
4. 生产部署建议使用密钥管理服务，而非明文 `.env`

---

## 9. 修改配置后的生效方式

| 配置类型 | 生效方式 |
|---------|---------|
| Settings 页保存 API Key | 立即生效 |
| Settings 页删除 API Key | 立即生效 |
| `.env` 任意项 | 重启后端 |
| 关键词组 | 立即生效，影响下次 AI 分析 |
